# Fish of Thieves: Fruits of Thieves
## Overview
- Added Fruits
- Added New Blocks and Items
- Added New Biome
- Added New Trees
- Added New Flowers
- Added New Advancements
- Bug fixes

## Fruits
### Coconut
- Added Coconut Tree
    - Generated in Beach biome
- Added Coconut Fruit
    - Can be falling from the tree if it has no support block or hit by projectiles
- Added Coconut Fronds
    - Can be used to collect rain water faster by placing Cauldron under the tail fronds
    - Can be placed vertical
- Added Coconut (Item)
    - Can be used to breed Pig
    - Can be used to grow a Coconut Tree by placing on the Sand
    - Can be found inside Shipwreck Supply Chest, Jungle Temple Chest and Seapost Supply Barrel
        - For Jungle Temple Chest, only if Jungle Template is generated in the Tropical Island

### Banana
- Added Banana Clusters
    - Has 3 states, Underripe, Barely Ripe, Ripe
    - Bees can be pollinating to make it grow faster
    - Can be harvested using Silk Touch
    - Using Bone Meal to make it grow faster, except for Underripe Banana Cluster
    - Requires Banana Leaves on top of the tree to make it grow and while raining
    - Requires Sunlight to grow for Barely Ripe Banana Cluster
    - Can be destroyed when hit by projectiles
- Added Banana Blossom
    - Can be crafted to Purple Dye
    - Can be placed under the solid block
    - Can be used to breed Pig
    - Bees can be pollinated
- Added Banana Tree
    - When using Bone Meal
        - On top of the tree will grow Banana Clusters, when raining it grows easier
        - At the bottom of the tree will grow Banana Shoots
    - Can be found in the Tropical Island biome
    - Can be found occasionally in the Sparse Jungle biome
- Added Banana Shoots
    - Can grow into Banana Tree
    - Can be placed in the Flower Pot
- Added Banana Leaves
    - Can increase leaves by using Bone Meal
    - Can be used to collect rain water faster by placing Cauldron under the tail leaves
    - Can be placed vertical
    - Can be occupied either the top half or the bottom half of a block
- Added Banana (Item)
    - Can be used to breed Pig
    - Can be found inside Shipwreck Supply Chest, Jungle Temple Chest and Seapost Supply Barrel
        - For Jungle Temple Chest, only if Jungle Template is generated in the Tropical Island

### Pineapple
- Added Pineapple Crop
    - Can be found in the Tropical Island biome
    - Can be found occasionally in the Sparse Jungle biome
    - When destroyed for each state
        - Crop State: Drop a Pineapple Seeds
        - Crown, Flowering: Drop a Pineapple Crown
        - Underripe: Drop a Pineapple Crown, with Silk Touch drop an Underripe Pineapple Block
        - Ripe: Drop a Pineapple (Item), with Silk Touch drop a Pineapple Block
- Added Pineapple Block
    - Has 3 variants, Underripe, Ripe Pineapple, Crownless Pineapple
    - When using Shears to cut the Ripe Pineapple Block, it drops Pineapple Crown and become Crownless Pineapple Block
    - Can be equipped on the head slot
- Added Pineapple (Item)
    - Can be used to breed Pig
    - Can be found inside Shipwreck Supply Chest, Jungle Temple Chest and Seapost Supply Barrel
        - For Jungle Temple Chest, only if Jungle Template is generated in the Tropical Island
- Added Pineapple Seeds
    - Can be used to breed Chicken

### Mango
- Added Mango Tree
    - Randomly generate Mango Fruit hanging around the leaves
    - Can be found in the Tropical Island biome
    - Can be found occasionally in the Sparse Jungle biome
- Added Mango Fruit
    - Can be falling from the tree if it has no support block, reached Raw or Mature state, hit by projectiles
    - Can be obtained by using Bone Meal on side of the Mango Leaves in all directions except on top of the block
- Added Mango Pit
    - Grows into Mango Sapling and requires sunlight
    - Obtained by eating Mango and Raw Mango
    - Can be placed in the Flower Pot
- Added Mango and Raw Mango (Item)
    - Can be used to breed Pig
    - When eating Raw Mango, it gives you random positive effects
    - Can be found inside Shipwreck Supply Chest, Jungle Temple Chest and Seapost Supply Barrel
        - For Jungle Temple Chest, only if Jungle Template is generated in the Tropical Island

### Pomegranate
- Added Pomegranate Plant
    - Can be placed in the Flower Pot
    - Using Shears to make it prevents further grow
    - Can be found occasionally in the Sparse Jungle biome
- Added Tall Pomegranate Plant
    - Using Shears to make it prevents further grow
    - Can be found occasionally in the Sparse Jungle biome
- Added Pomegranate (Item)
    - When crushed by a falling anvil, it transforms into Red Dye
    - Can be used to breed Pig
    - Can be found inside Shipwreck Supply Chest, Jungle Temple Chest and Seapost Supply Barrel
        - For Jungle Temple Chest, only if Jungle Template is generated in the Tropical Island
- Added Pomegranate Seeds
    - Can be used to breed Chicken
    - Can be placed in the Flower Pot

### Guardian Fruit
- Added Guardian Fruit Tree
  - Generate under the ocean floor

## Biome
### Tropical Island
- Generate near the Mushroom Island biome (Requires TerraBlender mod)
- Has all fruits and flowers generated
- Chicken, Pig, and Parrot can be found
- Features are almost same as the Sparse Jungle biome
    - Without Jungle Bush, Fewer melons, and no Big Oak trees
    - Has sand trail randomly generated around the biome
